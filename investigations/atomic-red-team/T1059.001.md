# SOC Investigation Report: PowerShell Execution (MITRE ATT&CK T1059.001)

## Project Overview
I simulated PowerShell T1059.001 using Atomic Red Team on a Windows 11 lab machine, investigated the resulting Sysmon and Wazuh logs to trace process activity and file drops, and documented the complete triage process into a structured incident report.

* **Incident Status:** Closed (Authorized Security Testing)
* **Risk Rating:** Low (Simulated Environment)
* **Impacted Host:** `Windows11-Lab` (`192.168.0.122`)
* **User Context:** `WINDOWS11\root` (Elevated / High Integrity)
* **MITRE ATT&CK Mapping:** 
  * **Tactic:** Execution
  * **Technique:** T1059.001 (Command and Scripting Interpreter: PowerShell)

---

## 1. Simulation Steps Executed
The following commands were executed in PowerShell to trigger the test:

```powershell
# Bypass script execution policy for the session
Set-ExecutionPolicy Bypass -Scope Process -Force

# Import Atomic Red Team module
Import-Module "C:\AtomicRedTeam\invoke-atomicredteam\Invoke-AtomicRedTeam.psd1" -Force

# Check and satisfy test prerequisites
Invoke-AtomicTest T1059.001 -GetPrereqs

# Execute Test 1 (Mimikatz execution test)
Invoke-AtomicTest T1059.001 -TestNumbers 1
```
